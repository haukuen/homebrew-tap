# homebrew-tap

Personal Homebrew tap for macOS casks.

## Install

```bash
brew tap haukuen/tap
brew install --cask venera
```

## Upgrade

```bash
brew update
brew upgrade --cask venera
```

## Uninstall

```bash
brew uninstall --cask venera
brew untap haukuen/tap
```

## Available Casks

- `venera`
